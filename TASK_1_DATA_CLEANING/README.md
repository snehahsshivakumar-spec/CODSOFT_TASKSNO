# CodSoft Data Analytics Internship - Task 1

## Data Cleaning and Preprocessing

### Dataset

Retail Sales Data

### Objective

The objective of this task is to clean and preprocess a retail sales dataset using Python and Pandas.

### Cleaning Performed

- Imported the retail sales dataset using Pandas
- Inspected the dataset structure and data types
- Identified and handled missing values
- Removed duplicate records
- Standardized inconsistent category values
- Standardized payment method values
- Converted the Date column to a proper date format
- Converted Unit_Price from text to numeric format
- Verified the cleaned dataset
- Exported the cleaned dataset as a CSV file

### Tools Used

- Python
- Pandas
- NumPy
- Jupyter Notebook
- VS Code

### Files Included

- `Task1_Data_Cleaning.ipynb` - Jupyter Notebook containing the complete data cleaning process
- `CODSOFT_Task1_Retail_Sales_Raw.csv` - Original raw dataset
- `CODSOFT_Task1_Retail_Sales_Cleaned.csv` - Cleaned dataset

### Final Result

After preprocessing:

- Missing values: 0
- Duplicate records: 0
- Data types corrected
- Inconsistent values standardized
- Cleaned dataset exported successfully
