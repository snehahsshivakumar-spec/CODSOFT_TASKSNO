# CodSoft Data Analytics Internship - Task 2

## Exploratory Data Analysis (EDA)

### Dataset

Retail Sales Data

### Objective

The objective of this task is to perform Exploratory Data Analysis on the cleaned retail sales dataset and identify useful patterns, trends, and relationships in the data.

### Analysis Performed

- Analyzed the total number of transactions
- Analyzed total quantity sold
- Analyzed total sales
- Analyzed average unit price
- Compared sales across different categories
- Compared quantity sold across categories
- Analyzed sales by payment method
- Analyzed sales trends over time
- Examined relationships between quantity and unit price
- Identified unusual patterns in the dataset
- Derived useful business insights

### Tools Used

- Power BI
- Python
- Pandas
- Jupyter Notebook

### Key Findings

- The dataset contains 40 transactions after removing duplicate records.
- A total of 84 units were sold.
- Total sales are approximately ₹96K.
- Electronics contributes the highest sales among the categories.
- Sales vary across different payment methods.
- Sales activity changes across different dates.
- Quantity and unit price do not show a simple direct relationship.

### Files Included

- `TASK_2_EDA.pbix` - Power BI report containing the EDA visualizations
- `README.md` - Project documentation

### Result

The exploratory analysis helped identify sales patterns, category performance, payment-method trends, and relationships within the retail sales dataset.
